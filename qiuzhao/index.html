  • 排序规则：梯队优先（山东强对口 → 山东保底 → 外地强对口），梯队内按「档位 + 青岛/山东加成 + 截止紧迫度 + 更新新鲜度」打分。推荐排序下序号固定不变，标记已投 / 收藏 / 不符合都不会打乱顺序；想看还剩哪些，把「状态」切到只看待投即可。
  • S 档 · 强对口：岗位名直含景观 / 园林 / 环境设计 / 环艺 / 室内 / 空间设计 / 展陈装饰，与专业直接对接，优先投。
  • A 档 · 建筑规划：建筑设计、城乡规划、市政、装饰、文旅等，环境设计背景通常可投，机会量最大。
  • B1 档 · 设计迁移：视觉 / UI / 交互 / 3D / 渲染 / 数字孪生 / BIM，正好吃到你作品集里的数字孪生与 AI 影像实验，命中率最高的跨界方向。
  • B2 档 · 游戏影视：游戏美术、策划、影视动画。场景构建能力能用上，但多数偏游戏向，按需挑选。
  • D 档 · 专业对口：岗位名没直接命中，但「专业要求」写明设计类 / 艺术类 / 建筑类 / 不限专业。
  • C 档 · 通用岗：管培生、运营、市场、人力等不限专业岗，专业门槛低但竞争大，作保底。
  • 状态四档：待投（还没看）→ 过的时候：投掉了的点已投、想投但还没投的点收藏、不投的点不符合。标记后卡片不会跳走、序号也不变；想看短名单把「状态」只勾收藏，想看投过哪些只勾已投。
