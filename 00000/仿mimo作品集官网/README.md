## 交互特效

- **首页分层开场**：纹理淡入 →「方寸之间 / 想象之上」遮罩上推 → 自我介绍与按钮错落入场。
- **Hero 反色揭示**：圆形 `clip-path` 跟随光标，露出深色英文层 + 橙色光圈。
- **全页反色镜**：Hero 以外用 `mix-blend-mode: difference` 白圆跟随反色。
- 磁吸按钮、卡片 3D 倾斜、滚动进度条、列表错落入场等。
- 触屏 / 窄屏 / `prefers-reduced-motion` 自动降级。
- 参数：`js/main.js` → `bindHeroInvert()` / `bindInvertLens()`。
