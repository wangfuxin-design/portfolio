# 灵感家 · 全屋设计工坊

一个纯前端的可交互 3D 室内设计网站（一室一厅全屋模型），无需联网、无需安装任何环境。

## 怎么打开

直接**双击 `index.html`**，用 Chrome / Edge 浏览器打开即可。
Three.js 已下载到本地 `lib/` 文件夹，完全离线可用。

## 功能

- **全屋材质替换**：8 种地板（木地板 / 人字拼 / 大理石 / 仿古砖 / 水磨石）+ 9 种墙面（乳胶漆 / 条纹 / 格纹 / 波点墙布），一键应用到全屋
- **家具小模型随意换**：14 类家具（沙发、床、餐桌椅、衣柜、书架、落地灯、绿植、地毯……）可从家具库随时添加
- **每件家具可编辑**：点击选中后可拖动摆放、旋转 45°、逐部件换材质（布艺 / 木饰面 / 金属 / 台面 / 图案）、删除
- **氛围**：白天 / 黄昏 / 夜晚三种光照，夜晚落地灯自动点亮
- **视角**：全景 / 俯视 / 客厅 / 卧室 一键切换，支持鼠标旋转、平移、缩放和自动环视
- **灵感搭配**：一键随机生成整套软装方案
- **导出效果图**：随时把当前画面保存为 PNG 图片
- 快捷键：`R` 旋转选中家具 ｜ `Delete` 删除 ｜ `Esc` 取消选择

## 文件结构

```
室内设计工坊/
├─ index.html          页面入口
├─ css/style.css       界面样式
├─ js/app.js           全部逻辑（房间、家具、材质、交互）
├─ lib/three.min.js    Three.js r128（本地）
└─ lib/OrbitControls.js  相机控制器（本地）
```

所有地板、墙布、大理石、地毯等贴图均由 Canvas 程序化生成，没有任何外部图片或网络依赖。
